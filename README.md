# P6 — Projet de formation Front-end

**P6** est un projet réalisé dans le cadre de ma formation, visant à construire un site web front-end qui interagit avec une **API fournie par le centre de formation**. L’objectif est de montrer les compétences en HTML, CSS, JavaScript et la consommation d’une API REST.


## Objectif du projet

Le but de ce projet est de créer un site web **démonstratif** qui utilise une API REST. Ce site permet de :  
- Récupérer des données depuis l’API (par exemple des utilisateurs, des ressources, des contenus)  
- Afficher ces données de façon dynamique dans le front   
- Appliquer une bonne organisation front (HTML / CSS / JS) dans un contexte réel d’API

## Fonctionnalités
 
- Affichage d’une liste de ressources / entités provenant de l’API  
- Détail d’une ressource (page “fiche”) lorsqu’on clique sur un élément de la liste  
- Gestion des erreurs d’API (ex : affichage d’un message d’erreur si la requête échoue)  
- Design responsive pour une bonne expérience sur mobile / desktop  

## Technologies

Le projet est construit avec :  
- **HTML** : structure des pages  
- **CSS** : mise en forme, responsive design  
- **JavaScript** : logique front, appels API, manipulation du DOM  
- **Fetch API** ou **Axios** (selon ton choix) pour effectuer des requêtes HTTP  
- (Optionnel) un bundler ou un outil de build léger, si tu l’as mis en place
